# Automated Pinterest Marketing System & Multi-Project n8n Hub (100% Free 24/7 Stack)

A modular, production-hardened automation hub built on **n8n Community Edition**, **Hugging Face Spaces (Docker Free Tier)**, **Neon Serverless PostgreSQL**, **Cloudflare Workers AI + R2 + Cron**, **Hybrid Gemini + Antigravity AI**, **Google Sheets**, and **Pinterest Official API v5**.

---

## Multi-Project Hub Architecture (Adding New Automations)

You do **not** need a separate n8n server or Neon database for each new project. Your single **Hugging Face Space (`n8n-automation-hub`) + Neon Postgres (`n8n-hub`)** runs unlimited projects side-by-side:

1. **Naming & Organization inside n8n:**
   * Use **Tags** or project prefixes in workflow names: `[Pinterest] ...`, `[Facebook] ...`, `[Booking] ...`, `[TikTok] ...`.
   * Set **`00 - Universal Global Error Handler (All Projects)`** (`workflows/03-global-error-handler.json`) as the **Error Workflow** on *every* project—it updates Google Sheets when a Sheet `row_id` exists and sends Telegram alerts for all projects.
2. **Shared Credentials (Configure Once, Use Everywhere):**
   * `GEMINI_API_KEY`, **Google Service Account**, `TELEGRAM_BOT_TOKEN`, and `CF_WORKER_SECRET` are shared automatically across all workflows.
   * For new projects that use a different Google Sheet, enter that project's Sheet ID directly in its Google Sheets node (or add a project-specific env var like `BOOKING_GSHEETS_DOC_ID`).
   * For new webhook automations, n8n exposes `https://<your-space>.hf.space/webhook/<project-slug>` 24/7 automatically.
3. **Scaffold a New Project Workflow in 1 Command:**
   ```bash
   node scripts/new-project.mjs --name "my-new-project" --trigger webhook
   # or for a scheduled daily cron job:
   node scripts/new-project.mjs --name "daily-report-bot" --trigger schedule
   ```
   This generates `workflows/projects/<name>-workflow.json` pre-wired to Webhook/Schedule Trigger + Gemini AI + Telegram Summary, ready to import into n8n.

## Hybrid AI Architecture (Antigravity + Gemini Free Tier)

1. **Path A — Antigravity / Google AI Pro Pre-Fill (Zero External LLM Calls):**
   When `pin_title`, `pin_description`, and `image_prompt` are already populated in `Content_Queue` (for example, batch-generated by **Antigravity** in your workspace or **Gemini inside Google Sheets** via your Google AI Pro 5 TB plan), n8n's `IF Pre-Generated (Antigravity / Sheets AI)` node detects them and skips external LLM requests completely.
2. **Path B — 24/7 Cloud Generation via Official Gemini API (`gemini-2.5-flash`):**
   When a row only has `topic` + `target_link`, n8n calls Google's official `generativelanguage.googleapis.com` API using a free `GEMINI_API_KEY` from [Google AI Studio](https://aistudio.google.com/apikey) (no credit card required, zero unofficial OAuth risk).

## Deployment Runbook (\$0/month)

### 1. Create Neon Free PostgreSQL & Free Gemini API Key
1. Create a free project at [neon.tech](https://neon.tech) (name it `n8n-hub` so it serves all your future projects) and copy `DATABASE_URL`.
2. Create a free `GEMINI_API_KEY` at [aistudio.google.com/apikey](https://aistudio.google.com/apikey) (no billing/card needed; used only for topic-only rows when your PC is off).

### 2. Deploy Cloudflare R2 + Media Worker + Keep-Alive Cron
1. Install dependencies and authenticate Wrangler inside `cloudflare-worker/`:
   ```bash
   cd cloudflare-worker
   npm install
   npx wrangler login
   npx wrangler r2 bucket create pinterest-pins
   npx wrangler secret put CF_WORKER_SECRET
   npx wrangler deploy
   ```
2. Note your deployed `https://pinterest-media-worker.<subdomain>.workers.dev` URL.
3. Update `N8N_PUBLIC_URL` in [`wrangler.toml`](file:///C:/Projects/pinterest-n8n-automation/cloudflare-worker/wrangler.toml) once your Hugging Face Space is live, then redeploy so the `*/10 * * * *` cron keeps n8n awake 24/7.

### 3. Prepare Google Sheets Database
1. Create a Google Sheet with two tabs named **`Content_Queue`** and **`Published_Ledger`**.
2. Import [`templates/Content_Queue.csv`](file:///C:/Projects/pinterest-n8n-automation/templates/Content_Queue.csv) and [`templates/Published_Ledger.csv`](file:///C:/Projects/pinterest-n8n-automation/templates/Published_Ledger.csv).
3. Share the Google Sheet (Editor access) with your Google Cloud Service Account `client_email`.

### 4. Deploy n8n on Hugging Face Spaces
1. Create a new **Docker** Space (CPU basic 2 vCPU / 16 GB RAM, Free, e.g. named `n8n-automation-hub`) at [huggingface.co/new-space](https://huggingface.co/new-space).
2. Copy the files from `hf-space/` and the `workflows/` directory into the Space repository root and push.
3. Add all environment variables and secrets from [`.env.example`](file:///C:/Projects/pinterest-n8n-automation/.env.example) under **Space Settings → Variables and secrets**.
4. Open your Space URL, complete initial n8n owner setup, and create your **Google Service Account** credential.

### 5. Initial 1-Pin Test Protocol (Mandatory Before Enabling Schedule)
1. Import all three JSON files from `workflows/` into n8n.
2. In **Workflow 01** and **Workflow 02** settings, set **Error Workflow** to **`00 - Universal Global Error Handler (All Projects)`**.
3. In **Workflow 01**, open node **`Execute Sub-Workflow: Pinterest Publisher`** and select **`02 - Pinterest Publisher Sub-Workflow`**.
4. Confirm `MAX_PINS_PER_RUN=1`, `REQUIRE_APPROVAL=true`, and `PINTEREST_ENV=sandbox`.
5. Keep **Workflow 01** **Inactive** and click **Test workflow** (using `Manual Test Trigger (1 Pin)`). Row 1 in `Content_Queue.csv` uses the Antigravity pre-filled path automatically.
6. Inspect the Telegram approval preview (image `1000 × 1500`, SEO title, description, board ID) and tap **✅ Approve & Publish**.
7. Verify `Content_Queue` updates to `PUBLISHED`, `Published_Ledger` records the `content_hash` + `pinterest_pin_url`, and Telegram sends confirmation.
8. Only after this single-Pin test succeeds: switch `PINTEREST_ENV=production` (`PINTEREST_API_BASE_URL=https://api.pinterest.com`), optionally set `REQUIRE_APPROVAL=false`, and toggle **Workflow 01** **Active** for scheduled publishing.
